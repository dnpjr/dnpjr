## Featured Projects

### F1 Fantasy Optimisation

Deployed Python application for modelling and optimising teams in the official F1 Fantasy game.

The project combines live and historical data, expected-value modelling and mixed-integer optimisation to select teams under budget, roster and transfer constraints. It includes data validation, race-weekend logic, configurable modelling assumptions and an interactive Streamlit interface.

**Relevant skills:** Python, pandas, PuLP, Streamlit, external APIs, constrained optimisation, data pipelines, expected-value modelling, testing and debugging

**Live app:** https://f1optimise.streamlit.app/

**Repo:** `f1_fantasy_optimizer`

### Imbalanced Credit Default ML Pipeline

End-to-end machine-learning pipeline for credit-default classification, covering data preparation, model comparison, cross-validation and decision-threshold tuning.

Models include logistic regression, random forest and XGBoost, with PR-AUC used alongside ROC-AUC to evaluate performance under class imbalance. Threshold analysis increased minority-class recall from approximately 35% to 59%, while making the corresponding false-positive trade-off explicit.

**Relevant skills:** Python, pandas, scikit-learn, XGBoost, cross-validation, model evaluation, imbalanced classification, threshold optimisation

**Repo:** `ml_pipeline`

### Monday Range — Research & Backtesting Framework

Reproducible research and backtesting framework for investigating conditional market patterns using hourly financial data.

The project separates exploratory analysis from strategy evaluation and includes risk-based position sizing, layered exits, transaction-cost assumptions and performance and drawdown diagnostics.

**Relevant skills:** Python, pandas, time-series analysis, backtesting, performance evaluation, risk diagnostics, reproducible research

**Repo:** `monday_range`

### Drone Radar Interception Simulation

Browser-based simulation of radar sweep detection, target acquisition and dynamic pursuit assignment.

Built as an interactive prototype for exploring decision logic in multi-target tracking and interception scenarios.

**Relevant skills:** JavaScript, HTML Canvas, simulation, real-time visualisation, decision logic, target assignment

**Repo:** `drones`
